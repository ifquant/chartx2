# 0048 - 把右侧栏收成固定交易面板，而不是网页式滚动区

这次提交处理的是一个产品感问题，不是图表算法问题。桌面股票软件的右侧栏，本质上是工作台的一部分，不应该像网页侧边栏那样自己长出滚动条，把整个界面搞成“内容区 + 长页面”。

## 这次为什么要改

之前虽然已经修过一次桌面缩放，但右侧栏还是保留了网页式思路：

- 面板一多就允许自己滚动
- 信息块是简单堆叠，而不是明确的桌面分区
- `engine` 卡片这种开发味很重的块还占着桌面侧栏

这和真正的股票软件不一致。交易工作台更强调固定布局、稳定分区、整体一起缩放，而不是让某个区域单独变成长列表。

## 这次做了什么

1. 去掉了右侧栏里最不该出现在产品壳里的 `engine` 卡片
2. 把右侧栏重新收成三段：
   - watchlist 主面板
   - 简化 detail 面板
   - performance 面板
3. 禁止桌面态右侧栏自己滚动，让它重新成为固定工作台的一部分
4. 把阶段状态压缩进 detail 卡片底部，而不是另开一个开发态信息块

## 新人需要知道的两件事

1. “固定侧栏”不等于“内容永远不超”  
   真正的方法不是简单隐藏溢出，而是先减少不必要模块，再给重要模块更明确的空间分配。

2. 桌面工作台的优先级通常是  
   先保证主图、侧栏、工具栏这些大区块关系稳定，再考虑每个区块内部放多少信息。

## 这次还没做

- watchlist、detail、performance 还没接真实数据联动
- 还没有做真正的侧栏折叠、宽度调节或布局记忆
